# 実験指示 ex003 の続き：本実験の実行と、貼り戻した画像での評価

## 背景
report_003.md の作業前の確認で、予稿の値を再現できなかった。
予稿の cos類似度は Recon に近い一方、性別一致率と年齢RMSEは Self に近く、
3つの値を同時に与える条件が見つかっていない。

仮説：予稿の属性の評価は、**貼り戻した画像の全体**をDEXに入力し、元画像の全体と比べていた。
貼り戻した画像は顔の内側以外が元画像と同一であるため、DEXの予測が元画像と一致しやすくなる。
report_003 の5.4節は「正解ラベルに対する精度が下がる」ことを確認しただけで、
予稿の指標である「元画像との一致率」は確認していない。

## 作業1：本実験の実行（report_003 の9章の選択肢1）
- report_003 の7章で準備した `calibrate.py` と `generate.py` を、ex003 の指示どおり実行する。
- 予稿の絶対値との比較は行わず、Self、Recon、Other を基準とした相対的な比較としてまとめる。
- 先に50枚で試行して処理が正しく動くことを確認してから、1,000枚で実行する。

## 作業2：貼り戻した画像での評価（選択肢3）
1. 既存の環境は変更せず、CPU版の mxnet を入れた新しいconda環境を作る（既存環境を複製してから追加する）。
2. report_003 の再現用の200枚について、M0 の α = 0, 1, 1.5, 2 で、既存の `anonymize_image` により貼り戻した画像を生成する。乱数シードは report_003 の再現と同じにする。
3. 次の4通りでDEXの性別一致率と年齢RMSEを計算し、予稿の値（0.929 / 0.921 / 0.911 / 0.904、6.73 / 7.17 / 7.56 / 7.88）と比べる。
   - 切り出した顔 同士（report_003 と同じ。確認用）
   - 画像の全体 同士（元画像の全体 と 貼り戻した画像の全体）
   - 貼り戻した画像から改めて顔を切り出したもの 同士
   - Self についても、上の3通りを計算する
4. cos類似度は、切り出した顔のArcFaceで計算した場合と、貼り戻した画像から改めて顔を検出・切り出して計算した場合の両方を出す。

## 報告
- `report_004.md` に、作業1の結果（ex003 の冒頭の3つの問いへの答え）と、作業2の結果（予稿の値を再現する条件が見つかったか）をまとめる。
- 作業2で予稿の値に近い条件が見つかった場合は、その条件で作業1の主要な設定（Self、Recon、M0 の α=2、各方式の再識別率0.5の設定）も評価し、切り出した顔での評価と並べる。

## 指示の解釈と補完

- プログラムは引き続き `programs/ex003_ghost_image_eval/`，結果は `outputs/ex003_ghost_image_eval/` に置く．order_003 の「評価に使う画像」「比較する設定」「評価指標」「主要な図表」は，作業1でそのまま適用する．
- 新しいconda環境は `identity-anonymizer-mxcpu` とし，既存の `identity-anonymizer` を複製したうえで，`mxnet-cu112` をCPU版の `mxnet==1.9.1` に置き換え，`dill` を追加する．既存の環境は変更しない．
- 既存の `load_ghost_models` はランドマーク検出器をGPU (`ctx_id=0`) で初期化するため，CPU版の mxnet では動かない．モデルの読み込みだけを診断用のスクリプト側で行い（ランドマーク検出器は `ctx_id=-1` でCPUに配置），生成と貼り戻しは既存の `FaceAnonymizerPipeline.anonymize_image` をそのまま呼び出す．
- 「乱数シードは report_003 の再現と同じ」を厳密に満たすため，report_003 の再現と同じ手順で作ったソースの顔ベクトル ṽ を，あらかじめ決めたベクトルを返すだけの `Anonymizer` のサブクラス経由で `anonymize_image` に渡す．これにより，切り出した顔での評価は report_003 と同じ ṽ に対する結果になる．
- 作業2の「貼り戻した画像から改めて顔を切り出したもの 同士」は，元画像側は従来どおり元画像から切り出した顔，生成側は貼り戻した画像に顔検出と切り出しを改めて適用した顔，として比べる．
- 作業1の再識別率の水準での比較表は，各方式の設定を画像での再識別率について補間して作る．較正はベクトル空間での再識別率で行うため，画像での再識別率が目標から外れる場合は，その対応自体を結果として報告する．
- 任意とされていたArcFace以外の顔認識モデルによる再識別率は，時間が許す場合に限り実施する．
