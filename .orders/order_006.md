# Order 006：Cloudflare Tunnel による外部公開の手順の追加

## ユーザーの指示（原文）

> Cloudflareのセットアップと、サーバーを立てて外部URLを取得するまでをREADME.mdに加えて

## 指示の解釈と補完

- タスクの種類は「ドキュメントの作成」と判定した．ルートの `README.md` に，匿名化デモ（`programs/demo/`）のサーバーを起動し，Cloudflare Tunnel で外部URLを取得するまでの手順を節として追加する．コードは変更しない．
- 外部URLの取得方法は，アカウントやドメインが不要なクイックトンネル（短時間の試用向け）と，独自ドメインの名前付きトンネル（継続的な公開向け）の2通りを記載する．デモには認証が無いため，名前付きトンネルでは Cloudflare Access による利用者の制限をトンネルの起動前に行う手順とする．
- Cloudflare の無料プランのアップロード上限（100MB）に合わせ，デモのアップロード上限を下げる手順を含める．
- 記載するコマンドは，`cloudflared` の最新版（2026.10.1）のヘルプで実在を確認する．実際のトンネルの作成・起動（外部への公開）は行わない．
