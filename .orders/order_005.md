# Order 005：ブラウザで動画を匿名化するデモの追加

## ユーザーの指示（原文）

> リアルタイム性を捨てて、ブラウザで動画撮影、動画を匿名化、ブラウザで匿名化後の動画を表示、だとどうかな

（上の検討の結果を受けて）

> programsの中にdemo/として追加して
>
> それぞれの手法がブラウザから選べる
> ブラウザの撮影だけじゃなく、ローカルファイルをアップロードできる
> 動画中の全員の顔が入れ替わる
>
> の要件を満たして

## 指示の解釈と補完

- タスクの種類は「開発（Webアプリケーションのデモ）」と「ドキュメントの作成」と判定した．実験ではないため，学習・評価や `report_{n:03}.md` の作成は行わず，`document.md` に構成と実行方法を追記する．
- デモは `programs/demo/` に置く．既存の `src/`，`third_party/`，`programs/ex00*` のコードは変更せず，読み込んで再利用する．サンプリング方式は ex002 の `samplers.py`，GHOSTの生成とモデルの読み込みは ex003 の `ghost.py` を用いる．
- 貼り戻しに mxnet が必要なため，ex003 で作成した環境 `identity-anonymizer-mxcpu` で動かす．Webサーバーに必要な `fastapi`，`uvicorn`，`python-multipart` はこの環境にのみ追加する．既存の環境 `identity-anonymizer` は変更しない．
- 「それぞれの手法」は，これまでの実験で扱った M0（現行の α スケーリング），M2（属性関連度の上位 k 次元を保持），M3（M2 のソフト版），M3u（全次元を事前分布へ寄せる）と，比較用の Self（自分自身の顔ベクトル）とし，各方式のパラメータをブラウザから変えられるようにする．report_004 の較正の結果に基づく「弱・中・強」のプリセットも用意する．
- 「全員の顔が入れ替わる」は，既存の `anonymize_video` が1人しか追跡しないため，各フレームの全ての顔を検出し，ArcFaceの顔ベクトルで人物ごとに追跡したうえで，人物ごとに1つの匿名化後の顔ベクトルを割り当てて生成・貼り戻しを行う処理を新たに実装する．同じ人物は動画全体で同じ架空の人物に置き換わるようにする．
- 匿名化モデルに渡す顔ベクトルは，VAEの学習時と同じRGBの順序の顔画像から計算する（report_004 の8.6節の不整合を，デモ側で回避する）．
- 入力はブラウザでの撮影（MediaRecorder）とローカルファイルのアップロードの両方に対応する．アップロードされた動画は ffmpeg で一定の fps・高さ 720 画素以下・長さ 60 秒以下の mp4 に正規化してから処理し，出力はブラウザで再生できる H.264 の mp4（音声付き）とする．
- サーバーは既定で `127.0.0.1` で待ち受ける．カメラの使用には安全なコンテキスト（localhost または HTTPS）が必要である．
