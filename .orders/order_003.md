# 実験指示 ex003：GHOSTで生成した画像による匿名性と属性保持の評価

## 背景
report_002.md で、次のことがわかっている。
- 属性の評価に使った線形分類器は、実際の顔ベクトルに対しても性別の正解率が0.805しかなく、評価の道具として信頼できない可能性がある。
- 予稿（GHOSTで生成した画像をDEXで評価）では α=2 で性別一致率0.904だったが、ex002の線形分類器では同条件で0.68程度だった。
- 一方、コサイン類似度はベクトル空間（0.588）と画像からの再抽出（予稿の0.5734）でほぼ一致していた。
- ベクトル空間では、類似度0.5でも再識別率が0.9以上だった。
- GHOSTは埋め込みを正規化しないが、M2・M3の出力はノルムが実データより約3割小さい。

本実験の目的は、**GHOSTで実際に画像を生成し、再識別率をそろえた条件で、DEXによる属性の保持を比べる**ことである。
答えたい問いは次の3つである。
1. 再識別率を十分に下げたとき（例：0.1）、DEXで見た属性はどの程度保たれるか。現行のVAEのままで匿名性と属性保持を両立できるか。
2. M2・M3u は、同じ再識別率で現行方式 M0 より属性を保てるか。
3. ベクトル空間での評価（類似度、再識別率、線形分類器）は、画像での評価の代わりになるか。

## 制約
- 既存コードは変更しない。プログラムは `programs/ex003_ghost_image_eval/`、結果は `outputs/ex003_ghost_image_eval/` に置く。
- VAEの再学習はしない。ex002 で定義した方式（M0、M2、M3u）の実装はそのまま再利用する。
- ex002 のデータ分割（評価用 4,614 枚）、重複グループ、ラベルをそのまま使う。

## 作業前に確認すること
1. **GHOSTを動かせるようにする**：report_001 の10章のとおり、既存環境では `mxnet-cu112` が読み込めず、`load_ghost_models` が動かない。
   - どの処理が mxnet を必要としているかを特定する。
   - 既存のconda環境は変更しない。必要なら環境を複製するか新しい環境を作って対処する。
   - 対処に大きな変更（CUDAランタイムの追加など）が必要な場合は、作業前に方法を報告する。
2. **DEXの読み込み**：`weights/dex/` の年齢・性別推定モデルが動くことを確認する。予稿の評価で使った処理（前処理、顔の切り出し）がリポジトリにあれば、それと同一にする。
3. **予稿の再現**：評価用データから200枚を選び、M0 の α=0, 1, 2 で画像を生成して評価する。予稿の表の値（cos類似度 0.741 / 0.685 / 0.573、性別一致率 0.929 / 0.921 / 0.904、年齢RMSE 6.73 / 7.17 / 7.88）と比べ、パイプラインが予稿と同じであることを確認する。**cos類似度が予稿から0.03以上ずれる場合は、先に進まずに報告する。**
4. **線形分類器の健全性の確認**：ex002 の分類器で、正則化の強さ（C の掃引）、収束の警告、標準化の有無を確認する。あわせて、UTKFaceの元画像に対するDEXの性別正解率を求め、線形分類器（0.805）と比べる。

## 評価に使う画像
- ex002 の評価用データから **1,000枚** を選ぶ。性別・人種・年代でなるべく偏らないよう層化抽出し、乱数シードは0で固定する。ラベルのパースに失敗した5枚は除く。
- 最初に50枚で試行して1設定あたりの処理時間を測り、全体の所要時間を見積もって報告する。全体が6時間を超える見込みなら、枚数を減らす案を添えて報告する。
- 匿名化の対象画像そのものをGHOSTのターゲット（向きや表情の土台）とし、各方式で得た ṽ をソースの埋め込みとして渡す。

## 比較する設定
ex002 のベクトル空間での結果（表9、図7）から、**再識別率 top-1 が約0.9、0.5、0.1 になるパラメータ**を方式ごとに選ぶ。補間で求めた値に最も近い掃引点、または補間した値そのものを使い、選んだ値を報告する。

| 記号 | 内容 | 目的 |
|---|---|---|
| Self | 元の v をそのままソースに使う（自分自身との顔交換） | GHOSTによる劣化の上限を測る |
| Recon | v₀ = decoder(μ) をソースに使う（M0 の α=0） | VAEの再構成による劣化を測る |
| M0 | 現行方式。再識別率 0.9 / 0.5 に相当する α と、α=5 | 現行方式 |
| M2 | k=32 と k=64。それぞれ再識別率 0.9 / 0.5 / 0.1 に相当する設定 | 提案方式（ハード） |
| M3u | 再識別率 0.9 / 0.5 / 0.1 に相当する γ | 次元を選ばない置き換え |
| Other | ランダムに選んだ他人の実際の v をソースに使う | 属性が保持されない場合の下限 |

**ノルムの補正**：Self と Other 以外の全設定について、次の2通りで生成する。
- 補正なし：ṽ をそのまま渡す
- 補正あり：ṽ を実データの顔ベクトルの平均ノルム（22.5、学習用データから計算）にスケーリングしてから渡す。ターゲット本人のノルムは使わない（本人の情報を持ち込まないため）。

サンプル数は各画像・各設定で1本とする。乱数シードは0で固定する。

## 評価指標
生成した画像それぞれについて以下を計算する。

**匿名性**
- 生成画像から再抽出したArcFaceベクトル v_gen と元の v のコサイン類似度
- 再識別率 top-1 / top-10：v_gen をクエリとして、全 23,125 枚の実ベクトルから最も近いものを探し、元の画像（またはその重複グループ）が上位に入る割合
- （任意）ArcFace以外の顔認識モデルが用意できる場合は、そのモデルでも再識別率を計算する。生成と評価に同じArcFaceを使う循環を避けるため。

**属性の保持（DEX）**
- 性別の一致率：DEX(元画像) と DEX(生成画像) の性別が一致する割合
- 年齢：|DEX(元画像) − DEX(生成画像)| の平均と、予稿と同じ定義のRMSE
- 人種はDEXでは推定できないため、参考として、v_gen に ex002 の線形分類器を適用した一致率を載せる。

**画像の品質**
- 生成画像での顔検出の成功率
- 方式ごとに12枚程度を並べた比較画像（元画像、Self、Recon、各方式・各再識別率の水準）

**ベクトル空間の評価の妥当性**
- cos(ṽ, v)（ベクトル空間）と cos(v_gen, v)（画像から再抽出）の散布図と相関
- ベクトル空間での再識別率と、画像での再識別率の対応
- 線形分類器による ṽ の性別予測と、DEXによる生成画像の性別予測の一致率

## 中断して報告する条件
- GHOSTの環境を、既存環境を変更せずに用意できない場合
- 予稿の再現でcos類似度が0.03以上ずれる場合

## 指示の解釈と補完

- タスクの種類は「機械学習（学習済みモデルを用いた画像生成と評価）」と「レポート・ドキュメントの作成」と判定した．VAEとGHOSTの学習は行わない．
- mxnet を必要とするのは `coordinate_reg/image_infer.py` の `Handler`（106点ランドマーク検出）のみであり，これは生成した顔を元画像へ貼り戻す `get_final_image` でしか使われない．予稿と同じ評価処理 `identity_anonymizer.evaluation.metrics.evaluate_single_image` は，貼り戻す前の顔画像 `y_st` をArcFaceとDEXに入力する．したがって，顔検出器，生成器，ArcFaceだけを読み込めば，環境を変更せずに予稿と同じ生成と評価を行えると判断した．既存のconda環境 `identity-anonymizer` をそのまま用いる．
- 顔の切り出し，生成器への入力の前処理，ArcFaceの再抽出，DEXの前処理は，既存の `FaceAnonymizerPipeline.anonymize_image` と `evaluate_single_image` と同一の関数・同一の手順を用いる．1枚ずつではなくバッチで処理する部分は，既存の関数と出力が一致することを確認してから用いる．
- 予稿の本文の表には α=1.0，1.5，2.0 の値が載っている．指示にある α=0 の値と合わせ，α=0，1，1.5，2 の4点で再現を確認する．再現用の200枚は，予稿の評価が全画像の平均であることに合わせ，評価用データからの単純無作為抽出とする（層化しない）．
- 本実験の1,000枚は，性別×人種×年代の80層に均等に割り当てる層化抽出とし，枚数が足りない層の不足分は残りの層に均等に再配分する．
- 「再識別率 0.9 / 0.5 / 0.1 に相当するパラメータ」は，選んだ1,000枚についてベクトル空間で各方式のパラメータを細かく掃引し直し（K=10），目標値に最も近いものを選ぶ．M2 のパラメータは保持する次元数 k だけであるため，目標の再識別率に相当する k を3つ選び，指示にある k=32 と k=64 がそれと異なる場合は追加の設定として加える．M0 は α=5 でも再識別率が0.5付近までしか下がらないため，0.9 と 0.5 に相当する α と α=5 を用いる．
- ノルムの補正に用いる平均ノルムは，ex002 の学習用データの顔ベクトルから計算する．補正の有無は同じ ṽ（同じ乱数）に対して適用する．
- Other のソースは，評価用データのうち重複グループが異なる画像から無作為に1枚選ぶ．
- 生成画像での顔検出は，生成した 256×256 の顔画像に既存と同じ顔検出器を適用して判定する．
- 任意とされたArcFace以外の顔認識モデルは，リポジトリに同梱されている `weights/ghost/antelope/glintr100.onnx` が利用できる場合に限り実施する．
