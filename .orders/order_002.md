# Order 002：属性次元を保持し，他の次元を事前分布から取るサンプリングの検証

## ユーザーの指示（原文）

# 実験指示 ex002：属性次元を保持し、他の次元を事前分布から取るサンプリングの検証

## 背景
report_001.md の診断で、次のことがわかっている。
- VAE（512-128-512、デコーダは線形1層）の出力は ṽ = v₀ + αW(s⊙z) と分解できる。
- 類似度は cos(ṽ, v) ≈ cos(v₀, v) / √(1 + α²ρ²) でほぼ完全に予測できる。
- 現行方式は μ（本人の成分）を残したまま直交するノイズを足すだけなので、類似度は薄まるようにしか下がらない。

本実験では、VAEの枠組みを保ったまま「本人の成分を置き換える」サンプリングを検証する。
仮説：**属性（性別・年齢・人種）を担う潜在次元は事後分布から、それ以外の次元は事前分布 N(0,1) から取る**と、
現行の α スケーリングより少ない属性劣化で類似度を下げられる。

## 制約
- 既存コードは変更しない。プログラムは `programs/ex002_partial_prior_sampling/`、結果は `outputs/ex002_partial_prior_sampling/` に置く。
- VAEの再学習はしない（学習済みの `weights/anonymizers/vae/vae_512_128.pt` を使う）。
- GHOSTによる画像生成はしない。評価はベクトル空間のみで行う。
- ex001 で抽出した顔ベクトルと画像パスの対応、実行環境の回避策はそのまま再利用してよい。
- 乱数シードは 0, 1, 2。本文の数値はシード0で示し、シード間のばらつきを併記する。

## 作業前に確認すること
1. **GHOSTがソースの埋め込みをL2正規化しているか**をコードで確認し、該当箇所を報告する。正規化している場合、以降の評価（属性分類器など）は全てL2正規化したベクトルで行う。
2. **UTKFaceのラベル**をファイル名 `[age]_[gender]_[race]_[date].jpg` から取得する（gender: 0=男性, 1=女性、race: 0〜4）。形式が崩れたファイル名の数を報告する。パースに失敗した画像が1%を超える場合は、先に進まずに報告する。
3. 重複画像（完全一致の419枚、cos ≥ 0.9 の組）を、後述するデータ分割で同じ側に入るようグループ化する。

## 実験A：潜在次元ごとの属性関連度
**目的**：属性を担う次元が少数の軸に集中しているかを確かめる。集中していなければ、次元を選んで固定するという案Aの前提が崩れる。

全画像の μ について、次元ごとに以下を計算する。
- 性別、人種：相関比 η²（グループ間の分散 / 全体の分散）
- 年齢：年代ビン（0–9, 10–19, …, 70+）での η² と、年齢とのSpearman相関
- 総合スコア r_j：3つの η² の最大値（別の定義も試した場合は併記してよい）

集中度の確認：
- r_j を降順に並べた棒グラフと、累積シェアの曲線
- **軸に揃っているかの確認**：μ の全128次元を使った属性分類器と、r_j 上位 k 次元（k = 8, 16, 32, 64）だけを使った分類器の精度を比べる。上位の少数次元で全次元に近い精度が出れば、属性は軸に揃っていると判断できる。

## 評価用の属性分類器
**目的**：生成した ṽ の属性を、ベクトル空間のまま判定する。ラベルは評価にのみ使う。

- 入力：実際のArcFaceベクトル v（確認1の結果に従って正規化する）
- 性別：ロジスティック回帰、人種：多クラスロジスティック回帰、年齢：リッジ回帰
- 重複グループを考慮して、学習用と評価用を8:2に分割する。評価用データでの精度（性別・人種の正解率、年齢のMAE）を報告する。
- 以降の評価は全て評価用データの画像で行う。

## 実験B：サンプリング方式の比較
**目的**：同じ類似度まで下げたときに、どの方式が最も属性を保てるかを比べる。

以下の方式を比較する（各画像・各設定で K=10 サンプル）。

| 記号 | 方式 | 掃引するパラメータ |
|---|---|---|
| M0 | 現行：f = μ + α s⊙z | α ∈ {0, 1, 1.25, 1.5, 2, 3, 5} |
| M1 | 比較対象：v に等方的なノイズを直接足す。ṽ = v + τ (‖v‖/√512) ε | τ を、M0と同じ類似度の範囲をカバーするよう設定 |
| M1b | 比較対象：v₀ に等方的なノイズを足す（再構成による劣化の影響を切り分ける） | M1と同じ |
| M2 | 提案（ハード）：属性関連度の上位 k 次元は f_j = μ_j + s_j z_j、残りの次元は f_j = z_j（事前分布） | k ∈ {0, 8, 16, 32, 64, 96, 128} |
| M2r | 対照：M2と同じだが、固定する k 次元をランダムに選ぶ | M2と同じ k |
| M3 | 提案（ソフト）：上位 k 次元は f_j = μ_j + s_j z_j、残りの次元は f_j = γ μ_j + √(1−γ²) z_j | k ∈ {16, 32, 64}、γ ∈ {0, 0.25, 0.5, 0.75, 0.9} |
| M3u | 対照：全次元で f_j = γ μ_j + √(1−γ²) z_j（次元を選ばない） | γ はM3と同じ |

**M2r と M3u が重要な対照**である。提案方式が対照より良いことが、「属性次元を選ぶこと」に意味がある根拠になる。

評価指標（画像ごとに計算し、全体の平均と5%〜95%点を示す）：
- 本人との類似度：cos(ṽ, v)、cos(ṽ, v₀)
- **再識別率**：ṽ に最も近い実ベクトルをデータ全体から探し、元の画像（またはその重複グループ）が1位になる割合。top-1 と top-10 の両方を出す。
- 属性の保持：
  - 性別・人種：分類器の予測 ṽ と v の一致率（正解ラベルとの一致率も併記）
  - 年齢：予測値の差 |pred(ṽ) − pred(v)| の平均
- 出力の自然さ：‖ṽ‖ の分布と、ṽ と最も近い実ベクトルとの cos（実データの分布から外れていないか）
- 多様性：同じ画像から得た2つのサンプル同士の cos

## 主要な図
1. **トレードオフ曲線（最重要）**：横軸に cos(ṽ, v) の平均（または再識別率）、縦軸に属性の一致率（性別、人種、年齢誤差のそれぞれ）をとり、方式ごとに1本の曲線を描く。
2. 同じ類似度での比較表：cos(ṽ, v) = 0.6, 0.5, 0.4, 0.3 の各点で、各方式の属性保持と再識別率を補間して並べる。
3. 実験Aの属性関連度の棒グラフと、上位 k 次元での分類精度の曲線

## 閉形式の確認（任意）

- M2 と M2r、M3 と M3u の差がほとんどない場合。その時点で結果をまとめて報告する。
- その他、想定外の挙動が見つかった場合。

## 指示の解釈と補完

- タスクの種類は「機械学習（学習済みモデルを用いたサンプリング方式の比較実験）」と「レポート・ドキュメントの作成」と判定した．VAEの再学習は行わないため，`train.py` による学習ループは作成しない．属性分類器はscikit-learnの線形モデルであり，評価の道具として学習する．
- 確認1の結果，GHOSTはソースの埋め込みをL2正規化していなかった．そのため評価は正規化しない生のベクトルで行う．線形の分類器・回帰器はノルムの影響を受けるため，L2正規化したベクトルで学習・評価した結果も参考として併記する．
- 重複グループは，ArcFace空間でコサイン類似度が0.9以上の組を辺とするグラフの連結成分として定義する．完全一致の画像はこの条件に含まれる．
- データ分割は重複グループを単位とする8:2の分割とし，乱数シード0で固定する．乱数シード0，1，2は，サンプリングのノイズとM2rのランダムな次元の選択に用いる．
- 実験Aの属性関連度は，指示のとおり全画像で計算して報告する．一方，実験Bで固定する次元の順位は，評価用データの情報が混入しないよう，学習用データのみで計算した関連度から決める．両者の順位の一致度を併記する．
- 「軸に揃っているか」の判断材料として，上位 k 次元に加えて，ランダムに選んだ k 次元での分類精度も対照として計算する．
- 「最も近い実ベクトル」はコサイン類似度で定義し，探索対象は顔ベクトルを抽出できた全23,125枚とする．
- M1とM1bの τ は，cos(ṽ, v) が約0.97から約0.24までを覆うよう {0, 0.25, 0.5, 0.75, 1, 1.25, 1.5, 2, 2.5, 3, 4} とする．
- M2rのランダムな k 次元は，乱数シードと k ごとに1組を選び，全画像で共通に用いる．
- 同じ類似度での比較表は，方式ごとの掃引点を cos(ṽ, v) の平均について線形補間して作る．掃引の範囲外の目標値は空欄とする．
- 中断条件のうち，実験Aの条件と対照との差の条件は，いずれも実験の実行自体は妨げないと解釈し，該当した場合はレポートの冒頭に明記する．
